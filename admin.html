Inventory console.

Drop in a photo batch, keep each filename as its item ID, then edit the listing details. Your browser writes the catalog and images into the local repo folder you select.

01 / Connect your repo folder

Open this admin page on GitHub Pages or localhost in a Chromium browser. Pick the local quarterbitgamesSTORE folder you cloned to this computer. No credentials or online writes are used here.

No repo folder selected.

02 / Import photos

Accepts JPG, PNG, WebP, and GIF. The exact filename stem becomes the item ID; for example HJ-BL-087.jpg becomes HJ-BL-087. Each new listing starts as a draft.

03 / Edit listing

Select an item below to edit it. Mark a listing Available and Published when its description, price, and checkout link are ready.

04 / Current catalog

Drafts stay private on the public catalog. Keep the original photo names intact so inventory IDs remain stable.
